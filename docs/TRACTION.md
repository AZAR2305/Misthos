# Traction log

Rules: real counterparties only; test USDC counts; team-run deals are listed separately and never counted. See `docs/PILOT_GUIDE.md`.

**What counts.** Only an independent business whose written **independence note** is in this file, AND whose wallet is listed with the same note in `frontend/content/origins.json` (a test checks both). If a wallet, account or invoice was created or controlled by us it is `team`, whatever anyone says. Anything undocumented is `unverified` and is not counted. **Shadow reports** are computations on a real business's data with no funds moved: they are listed under Engagement below and are never added to the numbers.
