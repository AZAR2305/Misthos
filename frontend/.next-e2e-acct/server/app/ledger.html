Ledger

The accounting for every early payment, and the agents' reasons for every decision.

What is this page?

Journal. One balanced entry per settled invoice, built from the chain. The buyer books the discount as income, the supplier as an expense, and the small success fee separately. Debits always equal credits.

Decision log. Each agent writes down what it saw, what it did and why, linking every entry to the one before. You can recompute the chain here: if anyone edited an old entry, the check names the first bad one.

Export. Download a CSV for a spreadsheet or a beancount file for plain-text accounting. Run bean-check on the beancount file before you rely on it.
