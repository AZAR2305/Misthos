What is this page?

Everything here is copy and paste. If a command fails, the doctor tells you what is missing: pnpm --filter @misthos/agent doctor. Nothing in the kit is simulated: it runs against a real chain, either Arc testnet or a local test chain on your machine.

What is in the kit

  • ✓InvoiceBook. The contract: verifies signed invoices and offers, enforces caps and the 50% rate ceiling, settles once. 40 tests.
  • ✓Agent core. Pure math in plain TypeScript: pricing, the offer ladder, the cash-aware allocator, the decision log. Tested on fixed examples.
  • ✓Wallet adapter. Signs and sends through a Circle Agent Wallet with the Circle CLI. Fails loudly and never falls back to another wallet.
  • ✓Two agents. Supplier and buyer, as separate processes talking over signed HTTP messages.
  • ✓This app. Invoices, offers, payments, ledger and live stats. It reads the chain directly.

1. Get the code and run the tests

git clone https://github.com/AZAR2305/Misthos.git cd Misthos pnpm install cd contract forge install OpenZeppelin/openzeppelin-contracts foundry-rs/forge-std --no-git forge test

Needs Node 20+, pnpm and Foundry.

2. Try it on a local test chain

No wallet extension logins, no faucet. A local chain with funded test accounts, the contract and a test USDC deployed for you.

anvil # terminal 1: a local chain cd contract # terminal 2 forge script script/DeployLocal.s.sol --rpc-url http://127.0.0.1:8545 --broadcast

It prints the addresses. Put them in frontend/.env.local (see frontend/.env.example), run pnpm dev, and add the local network to your wallet: RPC http://127.0.0.1:8545, chain id 31337.

3. Run it on Arc testnet

You need two Circle Agent Wallets (supplier and buyer), test USDC, a deployed contract and a model key. The full walk-through, with every website and command:

Open docs/SETUP.md
# connect an agent wallet (email code). Use a separate folder per agent. CIRCLE_CLI_HOME=~/.misthos/circle-supplier pnpm --filter @misthos/agent exec circle wallet login you@example.com --testnet pnpm --filter @misthos/agent exec circle wallet list --chain ARC-TESTNET --type agent pnpm --filter @misthos/agent doctor # shows exactly what is still missing pnpm --filter @misthos/agent buyer # then, in another terminal: pnpm --filter @misthos/agent supplier

Use it from Claude

The MCP server is not built yet

It is planned: it would let you ask Claude “what should we pay early this week?” and get the allocator's answer, with every write needing an explicit confirm. Until then, the buyer agent's POST /plan returns the same answer.

Honest limits

  • Testnet only, and the contract is unaudited. Do not use real funds.
  • Paying early from your own cash is not a loan, but rules vary by country. This is not legal advice.
  • Circle Agent Wallet spending policies exist only on mainnet, so the caps live in our contract.
  • Reputation (ERC-8004) and claim links need the server and registry work that is not built yet.
  • The mechanism, dynamic discounting, is old. What is new here is two independent agents, a cash-aware allocator, and signed offers enforced on chain.
